## Chat and editor rules

- Keep message roles, status, and timestamps easy to scan before adding brand expression.
- Use shimmer and streaming states subtly so they do not compete with the message content.
- Show tool and reasoning activity when it helps users trust or review the workflow.
- Treat the editor toolbar, drag handle, and menus as one writing surface.
- Keep recovery copy specific when generation, upload, or editing fails.
