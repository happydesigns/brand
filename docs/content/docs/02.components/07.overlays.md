## Overlay labels

Overlay titles should name the decision or object: `Review pattern`, `Delete token`, or `Project settings`. Avoid generic titles such as `Are you sure?` when the action can be named directly.

## Overlay rules

- Use a modal when the current task needs a focused decision before work continues.
- Use a slideover when the user needs context from the current page while editing or reviewing.
- Use a drawer for compact flows where bottom or edge placement fits the device.
- Keep destructive actions visible, named, and paired with specific recovery copy.
- Do not put essential instructions only in a tooltip or hover-only surface.
