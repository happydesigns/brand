## Data rules

- Use tables when users need to compare several values across the same dimensions.
- Use cards when each item represents one object, project, person, or decision.
- Keep avatars and user rows factual; identity cues should support recognition, not decorate the surface.
- Use disclosure only for supporting detail. Keep the primary fact, state, or action visible.
- Prefer semantic surface and border utilities over one-off color treatments in dense data views.
