## The decisions that matter

- Use graphite-filled actions for the strongest decision; reserve coral for focus and signature details.
- Keep hierarchy clear through surfaces, borders and typography.
- Preserve a comfortable reading rhythm in forms, content and navigation.
- Check real states, including focus, errors, disabled controls and dialogs.

The shared scenes live in `@happydesigns/id/studio`. Brand data lives in `src/brand/brand.studio.json`. The guide supplies meaning and assets; the scenes provide a consistent comparison.

For component APIs, props and full accessibility guidance, use the [Nuxt UI documentation](https://ui.nuxt.com/docs/components/button). The preview covers representative brand behavior, not every Nuxt UI component.
